<h1>CSS Selectors</h1>

1. Element Selector ( html element အတိုင်း style ရေး)
2. ID Selector (# သက်ေတနဲ့ရေး)
3. Class Selector ( . နဲ့ ရေး)
4. Attribute Selector (html element ရဲ့ tag အတွင်းက attribute နဲ့ style သတ်မှတ် )

##### # ပိုတိကျတဲ့  selector ကို priority ထားပြီး အလုပ်လုပ်တယ်
##### -!important ပါရင် အဲ့ဒီ selector ကို first priority ထားပြိး လုပ်


### # Selector Priority

1. !important
2. ပိုတိကျတဲ့  selector
3. if the selector is the same level, the last one is overwrite.
